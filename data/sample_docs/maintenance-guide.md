# Example Maintenance Guide

Before restarting a machine, notify affected operators and confirm the equipment is in a safe state. Follow the site lockout and tagout procedure before inspecting moving parts or electrical components.

Check the visible power cable, emergency stop, status indicators, and the most recent fault code. Record the fault code and timestamp in the maintenance log. Never bypass a safety interlock to make a machine run.

If the fault returns after a safe restart, stop repeated restart attempts and escalate to the on-call maintenance technician. Only trained and authorized staff should open electrical panels or remove guards.

After the machine is returned to service, document the action taken, parts replaced, and any follow-up inspection needed. This document is synthetic sample content created for this demo.
